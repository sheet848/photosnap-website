# 📸 Photosnap Website – Frontend Mentor Challenge

A fully responsive, accessible, and performant React website built for the [Photosnap multi-page website challenge](https://www.frontendmentor.io/challenges/photosnap-multipage-website-nMDSrNmNW). Designed to showcase frontend development skills with modern web technologies.

## 🔗 Live Demo

👉 [View Live Site](https://photosnap-website-two.vercel.app/)

## 🛠 Tech Stack

- ⚛️ **React** (with functional components)
- 🧩 **React Router** (for multi-page navigation)
- 🎨 **SCSS** 
- 💡 **CSS Grid + Flexbox** (responsive layouts)

## 🚀 Features

- Fully responsive across mobile, tablet, and desktop
- Pixel-perfect match to design (from Figma files)
- Accessible and semantic HTML structure
- Dynamic routing with React Router
- Clean, modular components

## 📁 Folder Structure

```
public/  
├─- assets/ # Images & icons

src/
├── react/
	|-- components/ # ui components
	|-- pages/ # site pages
	|-- utilities/ # scroll to top
├── sass/ # all css files
	|-- abstracts/
	|-- block/
	|-- composition/
	|-- global/
	|-- main.jsx 
├── data.js # Static content or mock data  
├── App.jsx  # Router paths
├── main.jsx
```
